# 创建第一个角色

角色是工作台的中心。人设、知识、记忆、声音和形象都挂在**这一个角色**上。换角色就是换一套完整的工作环境，记忆和知识不会跟着「当前窗口」走。

## 最简单的创建方式

1. 打开工作台，进入角色相关页面。
2. 新建角色，填写名字和一段清楚的人设。
3. 保存后进入对话，先说一句日常的话，确认模型真的在用这个人设回答。

人设是角色档案，不是每句对话都要再贴一遍的长 Prompt。欢迎语、说话方式、允许做什么，写在角色设定里即可。对话里如果说「帮我改人设」，会走角色自己的修改流程，并常常需要你点一次确认——不要同时在设置页再保存一次，以免两处不一致。

## 创建时实际会发生什么

每个角色会自带一个**只属于它的知识空间**。不是全站一个库、角色只是标签。

同名角色可以存在多个，后创建的不会覆盖先创建的。列表里认不准时，看你刚刚点进去的那一个，不要靠重名猜测。

## 从材料生成角色

如果你有文稿、设定集或参考资料，可以走「上传材料 → 生成草稿 → 挑选人设 → 确认成角色」这条路。

- 分析失败时，草稿仍会留下一份可用的兜底设定，不会把流程卡死。
- 已经确认过的草稿不能再改名字或人设，需要的话去改正式角色。
- **确认成角色，不等于资料已经进知识库。** 文档往往还要你在知识流程里确认索引；没确认就提问，角色说「没有」是正常的。

## 版本

改人设之前可以先存一版。之后可以对比、发布或回滚。回滚会把当时的设定（以及快照里记录的 MCP 授权）写回当前角色。

如果快照里的外部工具服务器已经不存在，发布或回滚会失败，角色不会被写到一半。全局开放给所有角色的工具，不会被某一个角色的版本覆盖关掉。

## 能力不要一次全开

装好模型、装好工具，和「这个角色被允许使用」是两件事。

| 你遇到的情况 | 通常意味着 |
| --- | --- |
| 资源页还没装语音 | 角色没法开口，先去[准备本地资源](./resources) |
| 资源已装，但角色没打开对应能力 | 对话里会被拒绝，提示当前角色没有权限 |
| 能力已开，但要写文件、联网或改设定 | 对话里出现确认卡片，等你点同意或拒绝 |

第一次建议：

1. 名字 + 短人设，先能闲聊
2. 再打开知识或记忆
3. 再绑定声音或形象
4. 最后才接 QQ、直播或外部工具

一次全开，后面很难分清「卡住是在等你确认」还是真的出错。

## 知识、声音、形象

- 给角色上传的文档，只进入这个角色的知识空间。
- 对话里开口，靠的是绑定到角色的音色，不是变声任务。
- 变声（RVC）是单独的长任务，完成后结果应回到**当前对话**，而不是让你去另一个下载页自行收尾。
- 形象口型跟角色正在播放的语音走。

## 内置指南角色

工作台会自带一个指南角色，用来在模型还没配好时带你熟悉界面。不要把它当试验品删除。没有配置真实 API Key 时，它可能用预设回复，而不是你的模型。

## 删除

删除角色是级联清理，不是「列表里藏起来」：对话、记忆、知识任务、相关草稿都会去掉。内置指南角色无法删除。

向量库若清理失败，不会把角色永远锁在删除按钮上；但删除后检索为空，应视为这个角色已经不在，而不是还可以问旧资料。
