# 创建第一个角色

**通过工作台创建一个可对话的角色，并逐步补充它的性格、知识、声音和 Live2D 表现。**

## 开始前

- 已完成[快速开始](./quickstart)，并能打开工作台；
- 已在“设置”中配置并测试可用的语言模型；
- 如果需要知识库、语音或 Live2D，提前准备对应资源。

## 操作步骤

### 1. 创建角色

打开角色管理，点击“新建角色”，填写角色名称和一句话定位。名称建议简短明确，例如“技术助手”或“项目资料员”。

### 2. 完善角色资料

补充以下内容：

- 角色负责什么；
- 希望使用什么语气回答；
- 遇到不确定内容时如何处理；
- 哪些操作必须先征得你的同意；
- 不应该执行哪些事情。

先保存最小资料即可，后续可以继续调整。

### 3. 添加知识资料（可选）

在角色的知识区域上传 Markdown、PDF、文本或项目资料。等待处理完成后，点击“确认索引”，再回到对话页提问。

### 4. 配置能力（可选）

在能力区域查看可用的工具、技能和外部连接。只启用确实需要的能力；涉及写文件、启动服务或修改外部系统的能力，保留确认步骤。

### 5. 绑定声音和 Live2D（可选）

在声音设置中选择可用音色，在 Live2D 设置中选择模型。完成后，语音输出可以驱动角色的口型和动作。

### 6. 修改或删除角色

角色列表中可以编辑资料、替换资源或删除角色。删除前确认关联的对话、知识资料和声音资产仍然不需要。

## 你应该看到什么

- 角色列表出现新角色；
- 对话页可以选中它并发送消息；
- 未准备的可选资源会显示为未就绪，不会影响基础文字对话；
- 角色页面能看到当前启用的能力和资源。

## 常见问题

### 创建后无法回答

回到“设置”检查语言模型是否连接成功、模型名称是否正确。

### 知识资料上传后问不到

确认处理已经完成，并点击“确认索引”。如果处理失败，先查看失败提示或重新处理。

### 能力已启用但不能使用

检查对应资源或外部服务是否已经启动，同时确认角色确实拥有该能力。
