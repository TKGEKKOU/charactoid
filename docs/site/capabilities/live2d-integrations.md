# Live2D 与外部接入

## Live2D

Live2D 作为表现层接收语音输出和运行事件：

- 对话页显示角色模型；
- 可进入更沉浸的全屏展示；
- 根据音频输出驱动口型；
- 根据运行状态驱动动作或状态表现；
- 模型资源由本地目录或资源管理接口提供。

## 外部接入

| 接入 | 作用 | 主要边界 |
| --- | --- | --- |
| B站 | 直播间事件、消息和输出 | 需要房间、登录态和连接生命周期 |
| OneBot11 | 机器人消息收发 | 需要 OneBot 服务和 Token |
| VTube Studio | 将表现输出连接到 VTuber 工作流 | 需要本地外部应用和协议配置 |
| WebSocket | 实时事件、语音流或集成状态 | 需要处理断线和重连 |

## 事件优先于页面耦合

外部集成不应读取前端组件内部状态，而应订阅运行事件、语音流或专用 WebSocket。这样同一条 Agent 任务可以同时服务 Web UI、桌面端和外部客户端。

接口入口见 [语音、RVC 与 Live2D API](/reference/api-voice) 和 [扩展与外部集成 API](/reference/api-integrations)。
