# 系统、状态与设置 API

## 健康检查

### `GET /api/health`（稳定）

确认主服务可访问。

```powershell
Invoke-RestMethod http://127.0.0.1:18000/api/health
```

响应包含 `status` 和 `workspace_id`。该接口成功不代表可选模型已安装。

### `GET /api/status`（稳定）

返回系统资源和运行状态摘要。适合启动后检查。

### `GET /api/launcher/progress`（可选）

返回桌面启动器或资源启动流程的进度。

## 系统与设置

`/api/system` 提供系统级状态和诊断接口；`/api/settings` 提供本地 Provider 和应用设置的读取、更新及探测。敏感值不应写入公开文档或提交到仓库。

## 状态码约定

| 状态码 | 含义 |
| --- | --- |
| `200` | 查询或更新成功 |
| `202` | 后台安装/启动任务已接受 |
| `400` | 请求参数不合法 |
| `404` | 资源或任务不存在 |
| `409` | 当前状态不允许该操作 |
| `422` | FastAPI schema 校验失败 |
| `500` | 服务内部错误，查看日志和阶段 |
