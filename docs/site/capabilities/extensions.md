# 扩展：Skill、Tool、MCP

## 三者的关系

- **Skill**：一组可加载的规则、说明和工具组合，改变 Agent 如何处理一类任务。
- **Tool**：具有输入 schema 的可调用动作，负责访问系统、文件或外部服务。
- **MCP**：连接外部工具服务器的协议适配层。

```text
角色授权
→ Skill 加载规则
→ Tool / MCP 工具进入可见集合
→ Agent 生成结构化参数
→ 工具执行并返回结果
→ Runtime 记录事件和副作用
```

## 安全边界

- 修改数据、发送消息或执行外部命令的工具必须声明副作用。
- MCP 服务只授予需要使用它的角色。
- 前端提交结构化配置，不直接把任意 Shell 暴露给模型。
- 凭据只放本地设置或环境变量，不提交到 Git。

示例和接口见 [扩展体系](/development/extensions)。
