# 对话与附件

对话页是你和角色共事的地方。普通闲聊可以只换一句回复；带目标的话会变成一次任务：可能分派工作、等你确认、让你补文件，再把结果放回**同一段对话**。

## 闲聊和任务

你可以直接问人设范围内的事，角色不必每次都「去干活」。当你提出要改设定、查它的知识、处理文件、变声或装资源时，监督者会决定：

- 只回答
- 先问你缺的信息
- 派给相应的能力去做
- 在动手前停下来让你确认

角色没有被授权的能力，会被明确拒绝，而不是悄悄去做。需要写文件、改数据或联网时，通常会先出现确认。

变声这类长流程必须由对话里的监督者发起，不会因为一句话里出现了「变声」就绕过确认直接开跑。

## 附件：两条完全不同的路

**对话附件**是「这一轮任务要用的文件」，例如参考音频、要处理的视频。在对话里用上传控件添加，不要把本机路径粘进输入框。

**知识文档**是「以后问这个角色时可以检索的资料」。要走到角色的知识库：上传 → 预览 → 你确认索引。对话附件不会自动变成知识。

知识文档默认体积上限比对话附件小（文档默认约 50MB，对话附件可达 512MB）。空的音频文件会被语音功能拒绝；那和文档上传不是同一条规则。

任务完成后，角色回复里附带的结果文件，应出现在当前对话中。不要默认去资源页另开一个下载窗口就结束。

## 确认卡片、补文件、取消

| 页面上的情况 | 你该做的 |
| --- | --- |
| 出现确认卡片，列出将要执行的动作 | 点同意或拒绝，不要在输入框解释 |
| 提示缺少文件或素材 | 用上传控件补齐，不要发本地路径 |
| 想停掉这次任务 | 用取消，而不是再发一句「算了」指望它自己停 |
| 说到一半关掉了页面 | 当前回复会中断；要继续应回到这段对话恢复，不要把上一句原样再贴一次 |

同意确认之后，任务才会继续。拒绝等于取消，角色不会当作已经完成。

已经结束的任务不能再批一次。进行中时不要复制粘贴同一问题——未完成的任务会挡住新的一句。

## 关掉页面不等于事情在磁盘上消失

关闭正在生成的回复，只会打断这一轮输出。已经在跑的变声、资源下载等，要真正停掉，需要走对话里的取消，而不是只关标签页。

换一个角色再聊，记忆和知识都不会带着走。每个角色是一套独立的工作台。

## 记忆

「记住……」才会写入记忆。对话变长后的摘要压缩，只是为了让后面还能聊，不是记忆本身。记忆存在服务端角色数据里，不在浏览器本地缓存。

## QQ、直播和其它入口

从 QQ 或直播进来的消息，仍然是**这个角色**的对话，不会另长一套人格。直播里不回答时，先看连接是否成功，再看该角色的对话里有没有出现那条用户消息。

## 建议你这样用

1. 一件事没结束前，不要重发同一句。
2. 等确认时点卡片；等文件时用上传。
3. 看失败原因，再决定是改设定、开能力，还是去装资源。
4. 换角色就是换工作环境。
5. 结果应回到当前对话，而不是让你到别的页面自行拼凑。
