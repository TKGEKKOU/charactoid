# 完成一次对话任务

**从普通问答开始，逐步体验知识检索、文件处理、等待输入、人工确认和任务结果。**

## 开始前

- 已完成[快速开始](./quickstart)；
- 已创建至少一个角色；
- 语言模型连接正常；
- 如果问题涉及知识、文件或语音，相关资源已经准备好。

## 操作步骤

### 1. 进入角色对话

打开工作台，在角色列表中选择刚创建的角色，进入对话页。

### 2. 先发送一个普通问题

例如：

> 请介绍一下你能做什么，并告诉我最适合从哪个功能开始。

观察回答是否符合角色设定。

### 3. 让角色使用知识资料

如果已经建立知识库，可以直接询问资料中的具体内容。回答中应能看到引用或证据；如果资料中没有答案，角色应明确说明，而不是凭空补全。

### 4. 提交一个需要执行的目标

例如：

> 检查当前语音和知识资源是否可用，并告诉我缺少什么。

或：

> 分析我刚上传的文件，并告诉我下一步需要确认什么。

页面会显示任务状态。执行过程中不要重复发送相同问题。

### 5. 处理等待输入和确认

如果任务需要文件、参数或你的决定，页面会显示等待卡片：

1. 按提示补充文件或填写信息；
2. 仔细阅读将要执行的动作；
3. 只有确认影响范围后，才点击“继续”；
4. 不想执行时选择取消。

### 6. 查看结果

任务完成后，结果会回到当前对话中。文件、音频和引用资料会以结果卡片展示；可以直接预览、下载或继续追问。

### 7. 处理失败

先查看失败发生在哪个阶段：输入、资源、模型、外部服务或文件写入。修正原因后可以点击“重试”；如果输入已经改变，重新创建任务通常更清楚。

## 你应该看到什么

- 普通问题直接显示角色回答；
- 复杂目标显示执行过程，完成后回到同一条对话；
- 缺少资料时出现明确提示；
- 有副作用的动作要求确认；
- 结果卡片包含可预览的文件、音频或引用。

## 常见问题

### 对话可以打开但没有回答

回到“设置”测试语言模型，并确认服务仍在运行。

### 一直停在等待输入

查看等待卡片缺少的文件或字段，补齐后再继续，不要只重复发送原问题。

### 任务被要求确认

这是正常的安全保护。阅读动作说明和目标范围，确定无误后再继续。
