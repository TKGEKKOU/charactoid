# 完成一次对话任务

第一次不要追求把语音、变声和直播全部打通。目标是：选一个角色，在同一段对话里提出一件事，看到它被认真执行（或明确地停下来等你）。

请先完成[快速开始](./quickstart)，并至少[创建一个角色](./character)。

## 1. 确认模型可用

打开设置页，测试连接成功。工作台能打开，还不等于对话能走通。

## 2. 进入一个角色的对话

用你刚建的角色，不要用内置指南角色当「正式任务」的试验对象——它在没配 Key 时可能只是预设回复。

## 3. 先发一句不会改电脑的话

例如问好、让它用自己的口吻做自我介绍。你应该看到：

- 同一段对话里出现你的话和角色的回复
- 回复符合人设，而不是通用助手腔

这一步失败：回到设置页，不要去装语音模型。

## 4. 再发一件需要能力的事

用自然语言交代目标，例如：

- 「把这段说明写进你的人设欢迎语」
- 「记住：我下周要演示创建角色」
- 「看一下你知识库里有没有上传过的那份说明」

这时对话可能不再是一句直接回答，而是一次**任务**：

- 角色开始分派工作，页面上能看到阶段变化
- 需要你点头时，出现**确认卡片**（写文件、改设定、本地知识不够要联网等）
- 缺文件时，出现**补文件**，而不是让你把磁盘路径打进输入框

确认和补文件不是一回事。缺音频、缺附件时去上传；要不要执行时去点卡片上的同意或拒绝。

不要在输入框里打「你继续吧」来代替点确认。也不要在任务还没结束时把同一句话再发一遍——那只会多一条消息，把进行中的任务挡住。

拒绝确认等于取消这次任务，角色不会假装已经做完。

## 5. 可选：让角色真正用上一份文档

如果你想验证知识，而不是只听人设：

1. 给**这个角色**上传文档
2. 等到可以预览后，确认索引
3. 再问文档里的具体事实

没确认索引就提问，角色说没有，是正确行为。上传对话附件，也不会自动变成知识库。

## 6. 怎样算第一次任务完成

同时满足即可：

1. 同一段对话里能看到你的话和角色回复
2. 若它去做了某件事，你能在对话里看到进展，而不是只有一个假转圈
3. 若你上传了文档并确认索引，追问能问到文中事实
4. 失败时有清楚说明，而不是空白转圈
5. 你知道自己是在等回复、等确认，还是等补文件

## 第一次刻意不要做

- 长视频变声
- Voice Studio 训练
- 改 Docker、关机一类本机管理
- 把 QQ 或直播当第一条输入
- 给角色一次性打开全部外部工具

那些放到资源和接入相关章节。第一次任务的意义是走通：**角色 → 对话 → 任务 →（可选）确认或补文件 → 结果仍在这段对话里**。
