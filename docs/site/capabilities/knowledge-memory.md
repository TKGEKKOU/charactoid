# 知识库与记忆

CHARACTOID 将“可检索资料”和“会话/长期记忆”分开管理：前者强调来源和证据，后者强调与角色和会话的关联。两者都可以被 Agent 按需调用，但不应混用数据边界。

## 知识资源

支持的主要处理方向包括 Markdown、PDF、网页或项目文档。处理过程包含解析、清洗、切分、向量化、索引、重排和引用。

## 记忆

记忆用于保留跨轮次或跨会话的用户信息、偏好和事实。写入记忆属于数据变更，应该经过明确的工具调用和状态记录，而不是让模型在普通回答中隐式修改。

## 最小使用流程

```text
创建知识空间
→ 上传文档
→ 等待处理任务
→ 确认或重试索引
→ 提问
→ 返回片段、来源和回答
```

## 判断结果是否可靠

- 回答是否包含可回到原文的来源；
- 片段是否真的支持结论；
- 重排分数是否达到当前阈值；
- 是否出现“资料没有提到”的明确提示；
- 是否把角色记忆误当成公共资料。

相关深度说明见 [RAG 设计](/concepts/rag)。
