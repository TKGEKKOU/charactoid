# 准备本地资源

先跑通文字对话，再按需安装可选能力。不要为了打开工作台就把全部模型下一遍。

CHARACTOID 把三件事分开：

1. **设置页**：语言模型、Embedding、联网搜索的地址和密钥
2. **资源页**：本机可安装的识别、语音、变声等环境
3. **角色能力**：这个角色可不可以使用已装好的能力

装好资源，不等于每个角色都已授权。

请先完成[快速开始](./quickstart)，并用一个角色走通[第一次对话任务](./first-task)。

## 建议顺序

1. 设置页配置语言模型，测试连接成功
2. 创建角色，完成一轮纯文字对话
3. 需要检索再安装 Embedding（以及可选的 Reranker），给角色上传文档并确认索引
4. 需要听写再装语音识别；需要角色开口再装 GPT-SoVITS，并按页面提示启动服务
5. 需要处理音视频或变声，再装 FFmpeg、人声分离、RVC
6. 需要形象，再把 Live2D 模型放到本机模型目录

## 资源页里有哪些

工作台管理的本机资源主要是这七项：

| 名称 | 什么时候才需要 |
| --- | --- |
| Embedding | 让角色检索知识库 |
| Reranker | 检索后需要更准的排序 |
| 语音识别（ASR） | 把你的语音变成文字 |
| GPT-SoVITS | 让角色用自己的音色说话 |
| FFmpeg | 音视频文件需要被正确读取 |
| 人声分离 | 从音视频里抽出干净人声 |
| RVC | 变声、音色转换长任务 |

页面上如果还写着 STT、TTS，指的是同一类能力，不是另外四套要再装一遍的东西。

## 在页面上怎么安装

打开资源页，按提示安装。你应该能看到进度、当前阶段，以及下一步该做什么：还要等、要安装、要检查、要启动服务，或已经就绪。

对 GPT-SoVITS 来说，「文件装好了」和「服务正在跑」是两回事。只有两者都满足，角色才能稳定出声。不要只看一个绿灯。

安装、取消、卸载都必须在这台电脑上的工作台里操作。用手机或另一台电脑的浏览器改本机资源，会被拒绝。

清理已结束的任务记录，不会卸载已经装好的文件。取消某一条正在进行的任务，才是停掉那一次下载或安装。

## 知识库相关

- Embedding 换了模型或维度后，旧的向量通常不能接着用，需要按提示重建，否则检索会空或报错。
- 文档要经过确认索引，角色才能问到内容。
- 知识文档和对话附件的大小上限不同，见[对话与附件](./conversation)。

默认使用本机嵌入式向量库，不需要 Docker。只有你主动改成远程向量服务时，才需要另外准备。

## 你应该看到什么

- 文字对话不依赖这些可选资源
- 某一项未就绪时，资源页能说明缺安装还是缺服务，而不是让整个工作台消失
- 对话里要使用某能力时，若角色没被授权，会说没有权限；若资源没装，会提示不可用或下一步去安装

## 常见问题

| 现象 | 先检查 |
| --- | --- |
| 把 Key 写进 `.env` 仍然没效果 | 到设置页保存。语言模型密钥不在 `.env` |
| 页面能开，对话失败 | 设置页测试连接，不是重装资源 |
| 换了 Embedding 后什么都搜不到 | 需要按新模型重建知识索引 |
| 文档上传成功但问不到 | 是否已确认索引；问的是不是**这个角色**的文档 |
| GPT-SoVITS 看起来已安装但没有声音 | 服务是否已启动；角色是否绑定了可用音色；角色能力是否打开 |
| 变声页面在，转换没有 | 是否从对话发起、是否补齐了音频、是否在等确认 |
| 清理任务失败 | 只能清理已经结束的记录 |
| 本机模型下载很慢或失败 | 网络、磁盘和（如需）GPU 驱动；可以稍后再装，先继续文字对话 |

更细的定位见[资源安装排查](/troubleshooting/resources)。接口清单见[资源 API](/reference/api-resources)。
